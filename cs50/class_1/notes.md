## Proceso de compilación

Source Code (Ej. C) -> Compilador (Ej.clang) -> Machine Code (0s y 1s)

## Compilar un programa en C

Navega hasta la carpeta

```bash
cd ruta/de/tu/carpeta
```

Compila el archivo

```bash
clang archivo.c -o programa
```

Ejecuta el programa

```bash
./programa
```
